# Gestión de Trabajos Académicos

App web para gestionar trabajos académicos de estudiantes. Permite registrar estudiantes con sus credenciales de acceso a la plataforma, agregar materias y hacer seguimiento del estado de cada trabajo.

## Funcionalidades

- Registro de estudiantes con usuario y contraseña de la plataforma
- Materias fijas: Lectura Crítica, Razonamiento Cuantitativo Saber Pro, Competencias Ciudadanas
- Campo "Otros" para trabajos adicionales
- Estados por materia: **Pendiente → Cargado → Calificado**
- Tabla expandible con estado general por estudiante
- Buscador y filtros por estado
- Estadísticas en tiempo real
- Sincronización en tiempo real con Firebase Firestore
- Archivo de estudiantes con materias completadas

## Tecnologías

- React 18 + TypeScript
- Vite
- Firebase Firestore
- CSS propio (sin librerías de UI)

## Ejecutar en local

```bash
npm install
npm run dev
```
